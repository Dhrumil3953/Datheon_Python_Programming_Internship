Hangman Word Guessing Game


About the Project

This is a simple command-line Hangman game developed using Python as part of the Datheon Python Programming Internship.


Features

Random word selection

Letter-by-letter guessing

Six incorrect attempts allowed

ASCII gallows drawings

Prevention of repeated guesses

Input validation

Win and lose messages


Technologies Used

Python

random module


How to Run

Install Python.

Download or clone this repository.

Open the project folder in a terminal.

Run the command
